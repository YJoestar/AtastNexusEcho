# NEXUS ECHO — Brand moodboard (research)

**Method and limits.** Two research subagents searched the web. Page fetching
was blocked, so everything below comes from **search-result summaries**, not
full articles; URLs are pointers to verify. Typefaces and hex colours were
rarely stated. A reference with nothing sourced is marked. Principles are
borrowed; no visuals are copied.

| Reference | What it shows | Borrowed | Avoided | Becomes |
|---|---|---|---|---|
| **The Operator** (Bureau 81 — not Spyderweb) [1] | The software *is* the game; an invented institution (FDI, 1992) | The brand states the player's role | — | A handset that is the Bureau's field system |
| **Signalis** [2] | Cold institutional tech + intimate portraits; "a copy of a copy" | One hybrid language; the *copy* idea | PS1/pixel type | The **echo** (displaced duplicate) |
| **Return of the Obra Dinn** [3] | One hard constraint everywhere; legibility over style (outlines) | A single discipline across UI and documents | 1-bit dither | Square corners + a 4-accent palette, always legible |
| **Stories Untold** [4] | Each device "method acting"; friction as brand | Each surface has a character | Deliberately bad UI | Records vs. lead vs. terminal surfaces |
| **Hypnospace Outlaw** [5] | Invented platform lets all content serve the brand | Reuse symbol + palette, don't multiply | Garish 90s web | One mark, one palette |
| **Crow Country** [6] | Era + abstraction vs. detail as signature | Contrast of detail (evidence) and calm (UI) | PS1 rendering | Evidence is the star; chrome stays plain |
| **Puppet Combo** [7] | Packaging (VHS box) as brand | Evidence stamp / labels as artefacts | VHS degradation | `stamp-recovered.svg` |
| **World of Horror** [8] | Tool limits become style; windowed UI | Constraint as identity | 1-bit art | Constraint = square + mono |
| **Iron Lung** [9] | Restricted senses; the instrument panel is the brand | The device as the world | — | Handset as the only window |
| **Shadows of Doubt** [10] | Skeuomorphic case files; pinning; string whose colour encodes state | Gameplay state in physical material | Cork board skin | Board links encode status (existing) |
| **Simulacra 2** [11] | Each app one job and identity; attention controlled by interaction, not colour highlights | One purpose per space | — | Case / Evidence / Board / Scan / Comms |
| **Duskwood / The Sign** [12] | Chat-driven; reviews criticise gated mini-games and monetised friction | Do not gate clues behind friction | Chat UI | No chat; no gating |
| **Dark Arrival** | **No UI case study found** | — | — | Not cited |
| **Backrooms: Lost Tape** | **Branding intent not sourced** | — | — | Not cited |
| Forensic forms / chain of custody [13] | Case no., item ID, handling log | IDs and ruled rows as texture | — | Record rows, mono IDs |
| ANSI Z535 [14] | A strict severity colour ladder reads instantly | One meaning per colour | Hazard-sign look | Semantic colour table |
| CCTV on-screen display [15] | Camera ID + timestamp in the corners | Persistent corner metadata | — | Surveillance frames |
| Analog horror [16] | Normal at first, slow intrusion; institutional tone | Calm default, rare disruption | Constant VHS filter | Event-driven glitch only |
| Diegetic UI in horror [17] | Cost is legibility and speed | Keep nav/text/targets plain | Holographic blue UI | Horror in content, not chrome |
| CRT effects [18] | Effects hurt text legibility; players want an off switch | Per-layer, low intensity, switchable | Global shader | Effects off text; off switch exists |
| Touch targets [19] | 44 pt (Apple), 48 dp (Material), WCAG 2.5.8 ≥ 24 px; thumb zone | 44–56 px, bottom actions | — | Tokens `touch-*` |
| Icon grids [20] | 24 dp, 20 dp live area, 2 dp stroke | 24 grid, 20 live area | 2 dp stroke (we use 1.5) | Glyph grammar |
